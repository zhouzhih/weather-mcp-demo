# 天气查询MCP演示项目API文档

## 概述

本文档详细描述了天气查询MCP演示项目提供的API接口。这些接口允许客户端获取天气数据、天气预报以及AI生成的天气分析和摘要。

## 基础信息

- **基础URL**: `http://localhost:8080`
- **响应格式**: JSON
- **认证方式**: 无（演示项目）

## 天气API

### 1. 获取当前天气

获取指定城市的当前天气信息。

**请求**:

```
GET /api/weather/current
```

**参数**:

| 参数名 | 类型   | 必填 | 描述     |
|--------|--------|------|----------|
| city   | String | 是   | 城市名称 |

**响应**:

```json
{
  "city": "Beijing",
  "country": "China",
  "current": {
    "date": "2025-03-27",
    "temperature": 25.0,
    "feelsLike": 26.0,
    "humidity": 60.0,
    "description": "Sunny",
    "windSpeed": 5.0,
    "iconUrl": "http://openweathermap.org/img/w/01d.png"
  },
  "forecast": []
}
```

**状态码**:

- 200: 成功
- 404: 未找到城市或天气数据
- 500: 服务器错误

### 2. 获取天气预报

获取指定城市的天气预报信息。

**请求**:

```
GET /api/weather/forecast
```

**参数**:

| 参数名 | 类型    | 必填 | 描述                   |
|--------|---------|------|------------------------|
| city   | String  | 是   | 城市名称               |
| days   | Integer | 否   | 预报天数（默认为5天）  |

**响应**:

```json
{
  "city": "Shanghai",
  "country": "China",
  "current": {
    "date": "2025-03-27",
    "temperature": 22.0,
    "feelsLike": 23.0,
    "humidity": 65.0,
    "description": "Partly cloudy",
    "windSpeed": 4.0,
    "iconUrl": "http://openweathermap.org/img/w/02d.png"
  },
  "forecast": [
    {
      "date": "2025-03-28",
      "temperature": 23.0,
      "feelsLike": 24.0,
      "humidity": 62.0,
      "description": "Sunny",
      "windSpeed": 3.5,
      "iconUrl": "http://openweathermap.org/img/w/01d.png"
    },
    {
      "date": "2025-03-29",
      "temperature": 24.0,
      "feelsLike": 25.0,
      "humidity": 60.0,
      "description": "Clear sky",
      "windSpeed": 3.0,
      "iconUrl": "http://openweathermap.org/img/w/01d.png"
    }
    // 更多天气预报数据...
  ]
}
```

**状态码**:

- 200: 成功
- 404: 未找到城市或天气数据
- 500: 服务器错误

### 3. 获取天气分析

获取指定城市的当前天气分析，由AI生成。

**请求**:

```
GET /api/weather/analysis
```

**参数**:

| 参数名 | 类型   | 必填 | 描述     |
|--------|--------|------|----------|
| city   | String | 是   | 城市名称 |

**响应**:

```
广州今天天气晴朗，气温25°C，体感温度26°C，湿度60%，风速5km/h。建议穿着轻便的衣物，注意防晒。适合户外活动，但请记得补充水分。
```

**状态码**:

- 200: 成功
- 404: 未找到城市或天气数据
- 500: 服务器错误

### 4. 获取天气预报摘要

获取指定城市的天气预报摘要，由AI生成。

**请求**:

```
GET /api/weather/forecast/summary
```

**参数**:

| 参数名 | 类型    | 必填 | 描述                   |
|--------|---------|------|------------------------|
| city   | String  | 是   | 城市名称               |
| days   | Integer | 否   | 预报天数（默认为5天）  |

**响应**:

```
深圳未来5天天气预报：周一至周三多云，气温22-28°C；周四和周五有阵雨，气温20-25°C。整体湿度较高，建议携带雨具，特别是周四和周五出行时。
```

**状态码**:

- 200: 成功
- 404: 未找到城市或天气数据
- 500: 服务器错误

## 测试API

### 1. 测试AI客户端

测试AI客户端的响应。

**请求**:

```
GET /api/test/client
```

**参数**:

| 参数名 | 类型   | 必填 | 描述           |
|--------|--------|------|----------------|
| prompt | String | 是   | 发送给AI的提示 |

**响应**:

```
今天北京天气晴朗，气温25°C，适合户外活动。
```

**状态码**:

- 200: 成功
- 404: 未找到响应
- 500: 服务器错误

### 2. 测试AI主机

测试AI主机的响应。

**请求**:

```
GET /api/test/host
```

**参数**:

| 参数名 | 类型   | 必填 | 描述           |
|--------|--------|------|----------------|
| prompt | String | 是   | 发送给AI的提示 |

**响应**:

```
根据最新气象数据，明天上海天气预计多云转晴，气温在22-26°C之间，湿度适中，风力较小。适合户外活动，但建议携带轻便外套，以防早晚温差较大。
```

**状态码**:

- 200: 成功
- 404: 未找到响应
- 500: 服务器错误

## 错误处理

所有API在遇到错误时都会返回标准的HTTP状态码，并在响应体中包含错误信息。

**错误响应示例**:

```json
{
  "timestamp": "2025-03-27T10:15:30.123Z",
  "status": 404,
  "error": "Not Found",
  "message": "未找到城市: Unknown City",
  "path": "/api/weather/current"
}
```
